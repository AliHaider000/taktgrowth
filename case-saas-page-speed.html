Interior design SaaS · WordPress · name withheld

About 4 seconds off every page load, and Core Web Vitals passed.

IndustryInterior design software, SaaS
WhereThe company's WordPress marketing site
PeriodCompleted May 2022
ServicesPage speed, Core Web Vitals, technical SEO, Google Analytics and Tag Manager

Where they started

An interior design software company's marketing site was losing visitors before the page had even finished loading. For a software company the website is the first demo: prospects judge the product by how the site feels.

The job had one focus: page speed and technical SEO on the WordPress build, with analytics and tag tracking kept intact throughout.

What I did, station by station

  1. Station 1 · MeasureLoad times recorded before any change, so the result could be measured again the same way afterwards.
  2. Station 2 · DiagnoseAn audit in Google PageSpeed Insights and Lighthouse showed what held each page back.
  3. Station 3 · BuildFixes applied on the WordPress build itself, aimed at what the audit found.
  4. Station 4 · DistributeNo new content or links in this job. Google Analytics and Tag Manager kept intact throughout, so every visit was still counted after the change.
  5. Station 5 · InspectMeasured again: about 4 seconds faster per load (-65%), desktop performance 95, largest contentful paint 1.1s, layout shift 0 and 0ms blocking time.

What to read carefully

This was a speed job, not a lead campaign, so there are no lead or ranking figures here. The scores are desktop lab measurements from Lighthouse and PageSpeed Insights after the work; mobile scores are not part of this result. The 65% is the load-time reduction measured before and after.
